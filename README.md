# 巴士天氣助手

iPhone 優先嘅單頁工具：九巴／龍運到站、香港天氣、24 小時預報同出門倒數。

🌐 網站：https://jl7121021.github.io/bushtml/  
⭐ GitHub 專案：https://github.com/JL7121021/bushtml — 覺得有用歡迎給個 star！  
目前版本：**v1.0.15**（頁尾會顯示）。

## 主要功能

- **巴士到站**：搜尋路線、方向、服務、車站，列出所有班次。
  - 「服務 1／2」係同一路線嘅唔同起點／走線，按你上車嘅車站揀。
- **路線消息**：巴士卡顯示所選路線同方向嘅九巴官方最新公告，按 `+N` 展開。
- **出門倒數**：一直開啟；按「出門通知」先會響，按停止後同一班次唔會再響。可選提示次數；「提前」掣旁邊的 ✎ 可自訂四個分鐘數並記住；亦可用「加入行事曆」設 iPhone 鬧鐘。
- **天氣**：香港天文台現況＋Open-Meteo 24 小時預報，可選每 1／2／3 小時。
- **新聞卡**：預設隱藏，按「顯示新聞」先載入九巴、政府新聞網、BBC 中文。
- **版面**：卡片的 ↑↓ 可調順序；背景同卡片對比已強化。

## 使用

1. 用 HTTPS 開啟（GitHub Pages 已準備好）。
2. iPhone Safari 可「分享 → 加入主畫面」。
3. 「出門通知」每次載入都要手動開；關掉時完全靜音。
4. 「背景音訊」係試驗功能（預設關）：開啟後用 Media Session 保持背景播放；關掉就完全靜音。
5. 背景執行／動態島唔係網頁能做到；重要提醒請用「加入行事曆」。
