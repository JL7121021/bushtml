# 巴士天氣助手

iPhone 優先嘅單頁工具：九巴／龍運到站、香港天氣、24 小時預報同出門倒數。

🌐 網站：https://jl7121021.github.io/bushtml/  
⭐ GitHub 專案：https://github.com/JL7121021/bushtml — 覺得有用歡迎給個 star！  
目前版本：**v1.0.26**（頁尾會顯示）。

## 主要功能

- **巴士到站**：搜尋路線、方向、服務、車站，列出所有班次。
  - 「服務 1／2」係同一路線嘅唔同起點／走線，按你上車嘅車站揀。
- **路線消息**：巴士卡顯示所選路線同方向嘅九巴官方最新公告，按 `+N` 展開。
- **出門倒數**：一直開啟；改提前分鐘會自動開啟通知。所有倒數（出門／準備出發／到站）都用 MM:SS 顯示分秒，同時保留出門／到站 HH:MM 時間；出門後倒數會自動轉做「到站倒數」，亦可以按「出門了」即時切換；按停止後同一班次唔會再響。提示更密同更大聲；可選次數；✎ 可自訂四個分鐘數並記住；亦可用「加入行事曆」設 iPhone 鬧鐘。
- **天氣**：香港天文台現況＋Open-Meteo 24 小時預報，可選每 1／2／3 小時。
- **新聞卡**：預設隱藏，按「顯示新聞」先載入九巴、政府新聞網、BBC 中文。
- **版面**：卡片的 ↑↓ 可調順序；背景同卡片對比已強化。

## 使用

1. 用 HTTPS 開啟（GitHub Pages 已準備好）。
2. iPhone Safari 可「分享 → 加入主畫面」。
3. 「出門通知」可手動開；改提前分鐘／按通知掣都會自動開（需批准通知權限）。關掉提示音時完全靜音。
4. 「背景音訊」係試驗功能（預設關）：開啟後用 Media Session 保持背景播放。所有倒數都用分秒（MM:SS）：「還有 03:00 出門」／「準備出發 · 00:15」／「出門了 · 08:00 到站」／「已到站」；出門／到站 HH:MM 時間一直顯示喺副標。關閉呢個掣就完全靜音。
5. 按「出門通知」或改提示次數時會自動啟動背景音訊（用該次觸控解鎖）；鎖屏／切 app 會保留返網頁入口。同一時間只有一個分頁持有音訊 session，返回頁面會取回控制權，減少動態島跳去其他 PWA／分頁。
6. 「出門了」掣常駐喺步行時間旁邊，按一下會**停止提示並關閉出門通知**，即刻切換到站倒數（靜音）。動態島會顯示 🚪 出門時間／🚌 到站時間；1–20 分鐘倒數會切換 `png/` 內嘅深藍底數字圖。外形同更新速度由 iOS 控制；重要提醒仍建議用「加入行事曆」。
