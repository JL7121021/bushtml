# 巴士到站 · 香港天氣 · 出門口倒數

單一檔案 `bus.html` 的靜態網頁工具，整合九巴／龍運實時到站、香港天氣、未來 24 小時預報、出門口倒數。適合放上 GitHub Pages 等靜態託管。

目前版本：**v1.0.8**（頁面頁尾會顯示）。

## 功能

- **巴士到站**：搜尋 KMB/LWB 路線、方向、服務、車站，並列出所有班次；可用位置尋找最近車站。
- **出門口倒數**：一直開啟，無需開關；按巴士班次倒數，到達「準備出發」時，若「出門通知」已開即播放提示音／震動。15 秒後顯示「出門口！」。按停止後不會自動重響，直到下一個出門時間。
- **提示次數**：可選持續／3 次／5 次／10 次，到達指定次數後自動停止，避免長時間響。
- **快速提前量**：除步進器外，提供 5／10／15／20 分鐘一鍵設定。
- **香港天氣 / 未來 24 小時分開顯示**：現時天氣、警告、溫度範圍、降雨提示與未來 24 小時每 3 小時預報分成獨立區塊；另加 **ECMWF 模型**作為第二天氣來源，方便交叉比對。
- **App 快速連結**：巴士卡與天氣卡各有 ↗ 連結，iPhone 會直接開啟 App Store 的「App1933 九巴／龍運」及「MyObservatory 我的天文台」頁面，已安裝可按「開啟」。
- **精簡版面**：已收緊卡片、間距、字級與逐小時格，在 iPhone 同一屏顯示更多內容。
- **可自行排列**：巴士到站、香港天氣、未來 24 小時可用 ↑↓ 調整順序，設定儲存於瀏覽器 `localStorage`。
- **保持螢幕常亮（Wake Lock）**：每次開啟頁面默認「開」，按鈕已移到頁尾；可嘗試在前景保持螢幕唔熄，需瀏覽器支援、HTTPS/localhost。
- **出門通知（實驗性）**：每次開啟頁面都默認「關」，需手動按「出門通知：開」才會響提示音／震動及發送通知（不會記住上次開啟狀態）；開啟時會先播放確認音作測試。關掉時完全靜音。網頁通知受瀏覽器／iOS 限制，未必可靠。
- **📅 加入行事曆**：按目前班次產生 `.ics` 行事曆檔案（提前 1 分鐘鬧鐘），這是在 iPhone 上最可靠的「時間到」提醒方式。
- **自動儲存**：路線、車站、主題、面板順序、天氣地點等儲存於本機瀏覽器，不會上傳到 GitHub。

## 使用

1. 將 `bus.html` 放到靜態託管（GitHub Pages/Netlify/Vercel/Cloudflare Pages）。
2. 用 HTTPS 開啟（`file://` 可能阻擋 API/CORS）。
3. iPhone Safari 可「分享 → 加入主畫面」。
4. 頁面已停用連點自動放大；雙指縮放仍可使用。
5. 「出門倒數」一直運作；「出門通知」每次開啟頁面都要手動按開，關掉時不會響。保持螢幕與測試音按鈕在頁尾。
6. 巴士／天氣卡上的 ↗ 可開啟對應 App 的 App Store 頁面（iPhone 直接開 App Store App）。

## 背景運行 / 子母畫面

- **不支援真正背景執行**：一般網頁在背景或鎖屏後，JS 計時器、API 更新、倒數可能被暫停。
- **Wake Lock**：只適用於頁面在前景時防止螢幕休眠，不等於背景運行。
- **通知提醒**：可作輔助，但 Web/iOS 限制較多；需要可靠背景提醒請使用「📅 加入行事曆」產生 iPhone 行事曆鬧鐘，或改用原生 App / Live Activity。
- **子母畫面**：Document Picture-in-Picture 主要支援桌面 Chromium，iOS Safari 不適合依賴；本專案未實作影片 PiP。

## 提示音與震動

- 手機瀏覽器要求先有使用者互動才可播放聲音。頁面**不會在載入或任何觸控時自動解鎖音訊**，避免干擾／暫停你正在聽的音樂；只有按頁尾「🔊 測試提示音」或按「出門通知：開」時才會解鎖。
- 開啟「出門通知」時會播放一段與出門提示不同的三音確認聲，順便測試喇叭／靜音開關是否正常。
- 提示音使用可解鎖的 HTML 音訊；iPhone 如開啟靜音開關，聲音仍會被遮罩，請關閉靜音並調高媒體音量。
- 震動使用 `navigator.vibrate`：Android Chrome 支援；**iOS Safari 不支援**，因此 iPhone 不會震動，只能依靠聲音／通知。
- 頁面在背景或鎖屏時計時器可能被暫停，提示音只在頁面開啟時可靠。
